# 在线状态与被控权限

U远程在已登录并运行时维持 publisher 信令会话、心跳和租约。网络中断会自动重连；退出应用或退出账号才结束在线会话。

“允许本机被控”只控制连接准入。关闭时设置服务端 `controllable=false`，取消当前画面、输入、文件传输及终端会话，保留 publisher。关闭状态仍消费信令，拒绝协助模式查询、密码挑战和延迟到达的连接请求。协助开关及自定义验证码设置独立保留。

重新开启后请求桌面授权并恢复 `controllable=true`，不重新登录或重建在线身份。被控时长限制仅关闭被控权限。关闭状态启动不申请桌面授权；授权不可用不影响先建立在线会话。

验证：ProtocolChecks 覆盖开关撤销、快速重新开启、协助准入以及验证码签名不泄露；真实客户端在线状态与重新连接需现场验证。
